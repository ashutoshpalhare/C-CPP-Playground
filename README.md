# C-CPP-Playground

A collection of C and C++ projects ranging from beginner to advanced, paired with a searchable, responsive project directory.

## Repository Structure

- `C/` — C language projects.
- `CPP/` — C++ projects.
- `index.html` — Static portfolio website (implementation begins in Phase 3).
- `README.md` — Project overview and documentation.

## Project Status

The initial collection contains 36 planned projects. Projects will be marked as planned, in progress, or completed based on their actual implementation. Links will only be enabled when the corresponding project destination exists.

## Technology

The portfolio website will use plain HTML, CSS, and vanilla JavaScript and will be compatible with GitHub Pages. No framework or build system is required.

## Learning Goals

- Practice C and C++ from fundamentals through advanced concepts.
- Keep each project self-contained with source code and its own README.
- Document compilation, usage, key features, and concepts learned.
